How to make Claude remember you

Instructions for Claude (every chat)

Available on all plans, including Free.

  1. Click your initials in the lower left, then Settings.
  2. Find Instructions for Claude (older guides call this "profile preferences").
  3. Paste your short version, or more of your file.

Projects

Free accounts can create up to 5 projects; paid plans have no limit.

  1. Go to Projects (claude.ai/projects) and click + New Project.
  2. Upload or paste your context file into the project's knowledge.
  3. Add project instructions, e.g. "Use my context file for every answer in this project."
  4. Start chats inside the project.

Memory

Memory is on by default for Free, Pro and Max on web, desktop and mobile. Each project keeps its own memory. Review and manage it in settings.

About Styles: custom Styles are moving to Skills, which are more technical. For most people, putting your answer-format preferences into Instructions for Claude does the same job.
