Does Microsoft Copilot remember you?

Yes, if memory is on. Microsoft Copilot keeps context about you in three separate places: saved memories, custom instructions and details it picks up from your chat history. Each has its own switch, and turning one off doesn't always delete what's already there. Here's how each one works, based on Microsoft's own help pages.

The steps below are for Copilot Chat signed in with a Microsoft 365 work or school account, which is what Microsoft's memory help pages describe. Microsoft says a new Copilot starting point ("Home") is still rolling out, and the personal Copilot app was redesigned in August 2026, so your menus may look different. Treat the steps as signposts.

The three kinds of Copilot memory

  • Saved memories: specific facts Copilot keeps, like your job role, common tasks or skills you want to improve. Microsoft says saving memories is on by default, and Copilot may ask whether you want something saved for future chats.
  • Custom instructions: what you write yourself about who you are and how you want answers formatted. Copilot applies them to future conversations.
  • Chat history: Copilot can make inferences from earlier chats. Microsoft's example: if you once mentioned a business trip to Japan, it might suggest travel tips when you ask what to pack. Microsoft says it doesn't remember every detail, only what's useful for personalizing answers.

On a work account, Microsoft also says Copilot can draw on your Microsoft 365 work data, usage signals and profile information to personalize answers when memory is on.

Tell Copilot to remember something

Just ask in the chat box. Microsoft's example:

Copilot, remember that I prefer Excel over PowerPoint for reporting.

Copilot saves it to Saved memories and shows a "Memory updated" notice. Microsoft says Copilot also merges related memories, updates outdated ones and removes them when you ask.

Add custom instructions

  1. In Copilot Chat, select ... Settings and more at the top right, then Chat settings.
  2. Select Personalization on the left.
  3. On the Custom instructions tile, select Edit instructions.
  4. Pick a suggested instruction or write your own: details about you and how you want responses formatted. Microsoft's example: "When summarizing a meeting, use bullet points for key details instead of paragraphs."
  5. Select Save instructions.

Custom instructions are the most reliable of the three, because you wrote them and Copilot doesn't rewrite them. Put anything you want applied every time here instead of hoping Copilot infers it.

See and delete saved memories

  1. Go to ... Settings and more > Chat settings > Personalization.
  2. On the Saved memories tile, select Manage saved memories.
  3. Select Delete next to any memory, or Delete all memories to clear them.

Watch out: turning the Saved memories toggle off stops Copilot from using them, but Microsoft says it doesn't delete the ones already saved. Delete them too if you want them gone. Microsoft Learn also notes that deleting a chat doesn't delete saved memories that came from that chat.

Stop Copilot from using your chat history

In Chat settings > Personalization, turn off Chat history (on a work or school account it may say Chat history & work insights). Microsoft says:

  • Inferences Copilot made from earlier chats are deleted after 30 days. With work insights, memories based on your work content go too.
  • If you turn the toggle back on within those 30 days, Copilot adds the deleted memories back.
  • To keep Copilot from drawing on one particular conversation, delete that chat. Microsoft Learn says if you delete every chat where something was mentioned, it's removed from chat history details within seven days.

On a work account: what your admin controls

Microsoft Learn's admin page adds a few things worth knowing:

  • Admins can turn off Enhanced personalization. If they do, Custom instructions, Saved memories and Chat history show as off and you can't turn them on.
  • Memories are stored in a hidden folder in your Exchange mailbox, and admins can search and delete saved and inferred memories with eDiscovery. Custom instructions aren't discoverable that way.
  • Your company's Purview retention policies don't apply to Copilot memory, so a "delete after three months" chat policy won't delete memories.
  • Admins can't restrict what kind of information goes into memory, and temporary chats are still visible to admins in Purview.

Microsoft notes personalization and memory are in preview and subject to change. In practice: don't tell a work Copilot anything you wouldn't put in a work email.

Make Copilot remember you the reliable way

Inferred memory is handy but unpredictable, and it stays inside Copilot. A short personal context file you write once works in Copilot's custom instructions and in ChatGPT, Claude, Gemini and Grok too. Paste the key parts into Custom instructions, or paste this line with your file underneath at the start of any chat:

Here is my personal context file. Read it and use it for everything in this chat. You don't need to summarize it back to me. Just reply "Got it" and wait for my first request.

[paste your context file here]
