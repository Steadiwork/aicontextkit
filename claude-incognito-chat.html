What is an incognito chat in Claude?

An incognito chat is a temporary Claude conversation that isn't saved to your chat history or to Claude's memory. Anthropic says incognito chats are available on every Claude plan: Free, Pro, Max, Ultra, Team and Enterprise. Here's how they work, based on Anthropic's own help pages.

Claude changes its menus often. The names below come from Anthropic's help pages as of November 2026; treat them as signposts if your screen looks different.

How to start an incognito chat

  1. Start a new chat outside of a project.
  2. Click the ghost icon in the upper right corner of the screen.
  3. Check that you're in incognito mode: the chat gets a black border and an Incognito chat label in the upper left corner.
  4. Chat as usual. When you're done, click the x in the upper right corner to close it.

You won't see the ghost icon inside a project. Anthropic says incognito mode is currently only available for chats outside of projects.

What an incognito chat skips

According to Anthropic, compared with a regular chat, an incognito chat:

  • Isn't saved to your chat history.
  • Doesn't use your existing memory, if you use Claude's memory.
  • Isn't added to future memory.
  • Won't come up when Claude searches your past chats from other conversations.
  • Isn't used for training.
  • Isn't included in your monthly recap.

Anthropic also notes that if you have the new Claude experience, Claude can't create files or run code in incognito chats.

What Claude can still see

Incognito skips memory, but not your profile. Anthropic says Claude can still access your profile information, such as custom styles and personal preferences, inside an incognito chat. So anything you've written about yourself in your settings still applies; only the memory Claude builds from your chats is left out.

What Anthropic still keeps

  • Incognito chats aren't saved to your history, but Anthropic says they are retained for 30 days by default, or longer if an Enterprise organization has set a custom data retention period.
  • On Team and Enterprise plans, incognito chats are included in the organization data exports available to account Owners, and on Enterprise plans they're included in the Compliance API. Anthropic says they're retained for 30 days for safety, or longer under your organization's data retention policy.

In other words, incognito keeps a chat out of your own history and memory. It doesn't hide it from your employer's admins on a work account.

Incognito vs turning memory off for one chat

Claude has a second, lighter option. If you want Claude to skip memory for one conversation but still keep the chat, turn memory off for that chat instead:

  1. Start a new chat.
  2. Click + in the message box (on mobile, tap + next to the message box).
  3. Turn off Memory.
  4. Send your first message. You have to do this before the first message; once the chat starts, the setting can't be changed.

Claude won't use or add to memory in that chat, but unlike incognito, the chat stays in your chat history and Claude can still find it when searching past chats from your other conversations. This also works inside projects, where incognito isn't available: a project chat started with memory off doesn't use your memory or the project's memory. On the web and desktop, a crossed-out memory icon appears next to the chat title.

Anthropic notes the Memory option doesn't appear in the + menu if memory is already off for your account or organization, if your plan doesn't include it, or inside an incognito chat.

Things to know before you close it

  • You can't convert it. Once you start an incognito chat, it can't be turned into a regular chat or saved to your history.
  • You can't reopen it. Once closed, an incognito chat is gone from your view. Copy anything important before you close it.

Give an incognito chat the context you want

Because an incognito chat skips memory, the reliable way to get the background you want is context you control. Save a short personal context file in Instructions for Claude (Anthropic says profile preferences still apply in incognito), or paste it at the start of the chat with this line:

Here is my personal context file. Read it and use it for everything in this chat. You don't need to summarize it back to me. Just reply "Got it" and wait for my first request.

[paste your context file here]
