How to make ChatGPT remember you

ChatGPT has three useful places for your context. Use one, two, or all three.

1. Custom Instructions (every chat)

Available on all plans, including Free, on web, desktop, iOS and Android.

  1. Web or desktop: Settings, then Personalization. Phone: Settings, then Customize ChatGPT.
  2. Make sure Enable customization is on.
  3. Paste your short version into the Custom Instructions field.
  4. Save. Changes apply right away.

Character limit: 1,500 on Free and Go; 5,000 on Plus, Pro, Business, Enterprise and Edu.

2. Memory

In Settings, Personalization, Memory, make sure memory is on (options vary by plan and region). In a chat, say "Please remember these facts about me:" and paste a few key lines. You can review or delete memories on the same screen. Memory is less predictable than Custom Instructions, so keep your file as the master copy.

3. Projects

Included on every plan. Files per project: Free 5, Go and Plus 25, Pro and business plans 40.

  1. Select New project in the sidebar.
  2. Upload or paste your context file.
  3. Open the project menu (•••), Project settings, and add instructions. Note: project instructions replace your global Custom Instructions inside that project.
  4. Start chats inside the project.
