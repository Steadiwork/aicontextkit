Why isn't ChatGPT remembering me?

If ChatGPT keeps forgetting your name, your job or how you like answers, one of a few settings is usually the reason. Here's what to check, based on OpenAI's own help pages, plus the one fix that doesn't depend on memory at all.

Memory features vary by plan, region, platform and workspace. If a setting below isn't on your screen, it may not be available for your account yet.

1. Memory is off, or only half on

Open Settings, then Personalization, then Memory. Depending on your account you may see Reference saved memories and Reference chat history:

  • Saved memories are details you explicitly asked ChatGPT to remember (or that it saved as useful). They're kept until you delete them.
  • Chat history lets ChatGPT pull relevant details from past conversations, but those details can change over time as ChatGPT updates what it thinks is useful.

Turning off Reference saved memories also turns off Reference chat history. If both are off, ChatGPT won't carry anything forward from earlier chats.

2. You're in a temporary chat

Temporary chats never create or update memories, even with personalization on. Before you start one, you can also pick Unpersonalized, which skips your existing memories and custom instructions, and you can't change that choice after the chat starts. If ChatGPT seems to know nothing about you, check that you're in a regular chat.

3. You expected it to remember everything

OpenAI says memory doesn't keep every detail from every conversation; ChatGPT decides what's relevant to each answer, and it doesn't search your history for every response. For anything it must always keep in mind, OpenAI recommends a saved memory over relying on chat history. In a chat, say something like:

Please remember these facts about me:
- I'm a [role] at a [type of company].
- I prefer short answers with the main point first.
- I'm currently working on [project].

4. It remembers the wrong thing

You can tell ChatGPT a memory is wrong or outdated, edit it in Memory settings, or ask "What do you remember about me?" to see what it's using. Choosing Don't mention this again reduces future mentions but doesn't delete the original chat. Deleting a chat also doesn't delete a saved memory made from it, so to fully remove something, delete both the saved memory and the chat where you shared it.

5. Your custom instructions aren't showing up

Memory and custom instructions are separate. Custom instructions are direct guidance you write once in their own settings field (Settings, then Personalization), separate from the Memory controls. Inside a project, though, project instructions replace your global custom instructions, so add your key details to the project too. See the ChatGPT setup guide for where each setting lives and the character limits by plan.

The fix that doesn't depend on memory

Memory decides on its own what to keep. A personal context file doesn't: it's a short document about you that you control, paste into custom instructions or a project, and reuse in Claude, Gemini or Grok if you switch. In any new chat, you can paste this line with your file underneath:

Here is my personal context file. Read it and use it for everything in this chat. You don't need to summarize it back to me. Just reply "Got it" and wait for my first request.

[paste your context file here]
