How Claude Projects keep your context

If you want Claude to stop starting from zero on a recurring piece of work, a Project is the workspace for it. Here's how Projects differ from account-wide Instructions for Claude, what actually carries from chat to chat, and where to put a personal context file, based on Anthropic's help pages.

Projects are available to all Claude users, including Free. Free accounts can create up to 5 projects. Menus change; treat setting names as signposts.

Projects vs Instructions for Claude

Instructions for Claude (in Settings) apply to every conversation on your account. Use them for standing preferences: how you like answers, terms you use often, and general rules.

Project instructions apply only inside that project. Anthropic recommends them when you need project-specific context, a particular workflow, task requirements, or a role Claude should play in that workspace.

You can use both. Put "who I am and how I like answers" in Instructions for Claude, and put "what this project is for" in the project's own instructions.

Create a project

  1. Open Projects in the left side of your account, or go to claude.ai/projects.
  2. Click + New Project.
  3. Give it a name and description. Claude does not see the name or description, so put anything Claude must know into instructions or knowledge instead.
  4. On Team or Enterprise plans, choose whether the project stays private or is shared with your organization.

What actually carries across chats

Anthropic is explicit: context is not shared across chats inside a project unless you add it to the project knowledge base. A long chat's details do not automatically become available in the next chat in the same project.

To make something stick for every chat in the project:

  1. On the project's main page, use the knowledge panel on the right.
  2. Click + and upload documents, text files or code snippets Claude should always have.
  3. Click Set project instructions, write how Claude should behave in this project, and save.

On paid plans, when project knowledge nears the context-window limit, Claude can switch into RAG mode to expand capacity.

Project memory (separate from other projects)

Memory is on by default for Free, Pro and Max on web, desktop and mobile (Team and Enterprise need an owner to enable it). Each project has its own memory:

  • Inside a project, Claude can use that project's memory plus your memory from chats outside projects.
  • It does not use memory from other projects.
  • New memories made in the project are saved to the project. With memory on, Claude may also reference them in chats outside projects.
  • To keep a project's memory fully separate, turn off Use account memory under Memory on the project's page.
  • To skip memory for one chat, turn off Memory in the + menu before your first message.

Where to put your context file

  1. Short version → Instructions for Claude (account-wide), so every chat knows who you are.
  2. Full version → upload into the project's knowledge, and summarize the project-specific rules in Set project instructions.
  3. For a one-off chat outside a project, paste the universal line plus your file at the start of the chat (see the Claude setup guide).
Here is my personal context file. Read it and use it for everything in this chat. You don't need to summarize it back to me. Just reply "Got it" and wait for my first request.

[paste your context file here]
