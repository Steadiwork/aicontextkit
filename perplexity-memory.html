Does Perplexity remember you?

Yes, unless you turn it off. Perplexity can draw on two things it learns about you, saved memories and your search history, plus anything you write yourself in custom instructions or a Project's instructions. Each one has its own setting. Here's how they work, based on Perplexity's own Help Center.

Perplexity changes its menus often. The setting names below come from its help pages as of November 2026; treat them as signposts if your screen looks different.

What Perplexity can remember

  • Memories: preferences, interests and information you share. Perplexity's example: if you often ask about Italian, Chinese or Mediterranean recipes, it remembers that the next time you ask for restaurant or recipe ideas.
  • Search history: your past questions and answers, used when they make a new answer more relevant.
  • Custom instructions: a free-text box in your settings for your preferences, interests and style. You write it; Perplexity doesn't.
  • Project instructions: instructions saved in a Project (up to 8,000 characters) that apply to every query run in that Project.

Perplexity says it uses memory and past searches only when they help with the question, and it cites any memory that shaped the answer in the answer's sources.

See what Perplexity remembers

  1. Go to Settings > Memory.
  2. Check the two toggles: Use search history (referencing past searches) and Notes (saving simple details from your sessions for future answers).
  3. Select Manage memories to open your full memory bank. You can search, filter and delete individual entries.

Max subscribers also see a Brain toggle, a separate memory system for Perplexity Computer with its own controls.

Delete a memory (or all of them)

  • One memory: in Settings > Memory > Manage memories, click the trash icon next to it.
  • Everything: use the clear all button in the same place.
  • A memory you spotted in an answer: referenced memories show up in the answer's sources. Delete it in Manage memories to stop it being used again.
  • A past search: to keep an old session from shaping future answers, delete it from your search history.

Perplexity says it may keep a log of cleared memories for up to 30 days for safety, debugging and to stop deleted memories from being re-created right away.

Turn memory off (and what that doesn't do)

Switch off Notes and Use search history in Settings > Memory. They're separate, so you can turn off one and keep the other. Watch out: Perplexity says turning memory off does not clear memories you already have. If you want them gone, delete them in Manage memories too.

For a one-off question you don't want remembered, use incognito. Perplexity says memory and past searches are always off in incognito mode, and questions asked there are never retained or used in memory.

Add custom instructions about yourself

Memories are inferred, so you don't fully control what gets saved. For things you want applied every time, use the Personalization page instead:

  1. Open your settings: click your avatar and choose All Settings (or go to perplexity.ai/account/details).
  2. Open Personalization.
  3. Fill in Your occupation and, if you like, Company name.
  4. Write your preferences, interests and answer style in Custom instructions.
  5. Optionally set Response Length (short, default or long) and Headers and Lists.

A short personal context file is a good fit for the Custom instructions box. Keep it to who you are, what you're working on and how you like answers.

Projects: instructions and memory for one topic

A Project keeps searches, files, instructions and connected tools together. To give one standing instructions:

  1. Open the Project and select See all settings in the right-hand panel (if the panel is hidden, select the Configure project settings icon at the top right first).
  2. Under General, add instructions. They're used for every query run in the Project, up to 8,000 characters.

Perplexity says each Project also has a Personal memory setting that controls whether queries in it can draw on the personal memory of whoever started the session. It's on by default and only the owner can change it. On personal accounts it's turned off, and can't be changed, once the Project has other members.

Is your memory used for training?

Perplexity says it may use memory content to improve its models. To opt out, turn off AI Data Retention in Settings > Preferences > Artificial Intelligence. On Enterprise accounts, Perplexity says memory content is never used to train models, memories belong to the organization rather than the user, and admins can turn memory off for everyone (which deletes existing memories).

Perplexity also says it tries to keep sensitive details like health or financial information out of memory, but memory favors what you ask about often. Review your memory bank now and then, and leave out anything you wouldn't want stored.

Make Perplexity remember you the reliable way

Inferred memory is handy but unpredictable, and it stays inside Perplexity. A short personal context file you write once works in Perplexity's Custom instructions and in ChatGPT, Claude, Gemini and Grok too. Paste it into Custom instructions or a Project's instructions, or paste this line with your file underneath at the start of any chat:

Here is my personal context file. Read it and use it for everything in this chat. You don't need to summarize it back to me. Just reply "Got it" and wait for my first request.

[paste your context file here]
